# Haptic Sound Pro (v2.0) — Озвучивание физической вибрации в играх

Специальная версия для игр! Игры (на движках Unity, Unreal Engine, OpenGL/Vulkan) вызывают **физический вибромотор телефона** напрямую, минуя стандартные системные кнопки Android.

В версии 2.0 реализован **высокочастотный детектор вибромотора (`VibrationSensorEngine`)**, который с частотой 200–400 Гц улавливает физическую дрожь моторчика смартфона в любой игре и мгновенно включает выбранный звуковой сигнал поверх игры.
